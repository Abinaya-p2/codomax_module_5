#  Module 5 – Data Science Mini Project

## Project Title
**Diabetes Health Indicators – Data Analysis Using Python**

## Project Overview
This project analyzes the CDC Diabetes Health Indicators dataset using Python. The aim is to explore health-related indicators, clean the dataset, create visualizations, and identify useful patterns in the data.

## Objectives
- Load and explore a real-world healthcare dataset.
- Check for missing values and duplicate records.
- Clean the dataset by removing duplicate rows.
- Analyze diabetes categories and health indicators.
- Create visualizations to understand patterns in the data.
- Export the cleaned dataset as a CSV file.

## Dataset
**Dataset:** CDC Diabetes Health Indicators  
**Original dataset size:** 253,680 rows and 22 columns  
**Target column:** `Diabetes_012`

The `Diabetes_012` column represents:
- `0` – No diabetes
- `1` – Prediabetes
- `2` – Diabetes

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Workflow
1. Imported the required Python libraries.
2. Loaded the CSV dataset into a Pandas DataFrame.
3. Explored the dataset using `head()` and `describe()`.
4. Checked missing values and duplicate records.
5. Removed duplicate rows from the dataset.
6. Analyzed diabetes categories and health indicators.
7. Created charts using Matplotlib and Seaborn.
8. Exported the cleaned dataset to a CSV file.

## Visualizations
- Diabetes category distribution
- Average BMI by age category
- Physical activity by diabetes category

## Key Learnings
- Data loading and exploration using Pandas
- Data cleaning and duplicate removal
- Exploratory Data Analysis (EDA)
- Data visualization using Matplotlib and Seaborn
- Extracting insights from healthcare data

## Project Files
- `healthcare_data_science_mini_project.ipynb` – Python notebook containing the analysis.
- `diabetes_health_indicators_cleaned.csv` – Cleaned dataset exported from the notebook.

## Disclaimer
This project is for educational and data analysis purposes only. The dataset contains health-related survey information and should not be used to diagnose medical conditions.
